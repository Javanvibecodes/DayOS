# Contributing to DayOS

Thank you for your interest in DayOS.

## Closed-Source & Proprietary Notice

DayOS is a **privately developed, closed-source product**. All code, designs, architecture, and binary releases are proprietary and owned exclusively by **Javanvibecodes**.

### Pull Requests & External Contributions
- **We do not accept pull requests (PRs)** from external contributors.
- Any open pull requests will be automatically closed without review.
- Forking this repository for public redistribution or derivative works without written permission is strictly prohibited.

### Bug Reports & Feedback
If you encounter an issue or have a feature suggestion, please open an Issue on the repository tracker (if enabled) or contact the maintainer directly.
